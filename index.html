AlgoVox / current implementation

The bot is one session with three focused agent nodes.

A LiveKit room carries audio in both directions. The shared AgentSession runs speech recognition, the LLM, speech synthesis, interruption handling, and one durable history. Each stage swaps only the active agent and its narrow prompt.

03

Agent nodes: the interview graph

Only one node is active at a time. A function tool returning the next agent is the graph edge. Handoffs keep the conversation but strip the old stage instructions from the new agent’s LLM context.

This is the entire current stage graph—there are no coding or follow-up nodes in the running bot yet.

IntroAgent

Node 2 · server/src/agents/discussion.py

Generates a short spoken question setup. One substantive candidate turn leads to the conclusion tool.

Node 3 · server/src/agents/conclusion.py

ConclusionAgent

Speaks a non-interruptible closing line, then directly shuts down the shared session.
